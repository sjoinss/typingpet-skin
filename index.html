    움직이는 GIF로 저장

    미리보기의 움직임을 그대로 GIF로 만들어요. 공유하거나 프로필 이미지로 쓰기 좋아요.

    투명 배경 GIF는 가장자리가 살짝 각져 보일 수 있어요.

    만든 이미지 넣는 방법
    1. Typing Pet 트레이 아이콘 → 설정 → 이미지 설정을 열어요.
    2. 기본 / 왼손 / 오른손의 이미지 변경에서 받은 PNG 파일을 각각 골라요.
    3. 세 장은 같은 캔버스·같은 위치 기준이라 자연스럽게 바뀌어요.
