# TypingPet 스킨 이미지 생성기

마인크래프트 스킨으로 [Typing Pet](https://github.com/swoonqx/TypingPet)용 **기본 / 왼손 / 오른손** 이미지(800×500 투명 PNG)를 만들어 주는 사이트입니다.

- 마인크래프트 아이디로 스킨 불러오기 (minotar.net → mc-heads.net) 또는 PNG 파일 업로드
- 상호작용 고르기: 책상과 키보드 / 나무 캐기 / 버튼 누르기 / 제작대로 조합하기
- 머리·몸 크기 조절 (꼬마 비율)
- 키보드를 누르거나 재생 버튼으로 움직임 미리보기
- 움직임을 GIF로 저장 (투명·단색 배경)
- 한 장씩 또는 ZIP으로 세 장 한 번에 내려받기
- `?name=아이디`를 주소에 붙이면 바로 불러옵니다

이미지는 브라우저 안에서만 만들어지며 어디에도 업로드되지 않습니다.

원목·버튼 받침·제작대 블록은 마인크래프트 원본 텍스처를 실행할 때 공개 에셋 미러(assets.mcasset.cloud, 실패 시 jsDelivr)에서 받아 씁니다. 이 저장소에는 원본 그림을 넣지 않았고, 받지 못하면 직접 그린 텍스처로 대신합니다. 주소에 `?scene=tree`(desk·tree·button·crafting)를 붙이면 그 상호작용으로 열립니다.
